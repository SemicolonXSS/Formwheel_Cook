📖 Formwheel Cook 설명서

1. 재료 꺼내기왼쪽 재료 보관함에서 원하는 재료를 누르면 작업대에 생깁니다. 같은 재료도 여러 번 꺼낼 수 있어요.
2. 선택하기작업대의 재료 카드를 누르면 주황색 테두리가 생깁니다. 여러 개를 동시에 선택할 수 있어요.
3. 자르기사과·양파·버섯·파프리카·고기 같은 재료를 선택한 뒤 자르기를 누르면 손질 상태가 붙습니다. 이미 자른 재료를 또 잘라도 추가 점수는 없습니다.
🧄 마늘 손질마늘을 자르면 다진 마늘, 으깨면 으깬 마늘이 됩니다. 섞은 뒤에도 원래 재료의 손질 상태와 평가 효과가 유지됩니다.
4. 섞기 — 개선됨!2개 이상의 재료를 선택하고 섞기를 누르면 선택한 재료가 사라지고 하나의 혼합물로 합쳐집니다. 혼합물 안에는 원래 재료가 모두 기억됩니다. 혼합물을 다른 재료와 다시 섞는 것도 가능합니다.
5. 가열하기재료 또는 혼합물을 선택해 전자레인지에 넣은 뒤 시간을 고르세요. 상태가 차가움/생 → 데워짐 → 익음 → 과조리로 변합니다.
6. 커피포트물 넣기 → 끓이기 → 뜨거운 물 꺼내기 순서입니다. 꺼낸 뜨거운 물은 작업대 재료처럼 사용할 수 있습니다.
7. 완성하기완성한 음식이나 혼합물을 선택해서 접시에 담은 뒤 완성! 평가하기를 누르세요.
냄비로 삶기물과 면·채소 등을 냄비에 넣고 끓이세요. 1분은 열 +30, 40초는 +20이에요. 면은 물 빼기 후 꺼내 소스와 섞어 보세요.
후라이팬으로 볶기·굽기재료를 넣고 40초 볶기(열 +24) 또는 굽기(열 +30)를 선택하세요. 연속 60초를 넘겨 가열하면 타므로 가열 사이에 뒤집기 / 젓기를 누르세요. 뒤집어도 이미 탄 상태나 과조리는 회복되지 않아요. 모든 시간은 게임 규칙이에요.

⭐ 점수 규칙

100점 만점이며 행동 횟수는 점수에 들어가지 않습니다. 대표 음식 조합과 얼마나 잘 맞는지, 필요한 재료를 적당히 썼는지, 손질과 가열이 적절한지를 봅니다. 재료를 무작정 많이 넣거나 같은 재료를 반복해서 넣으면 감점됩니다. 같은 완성 접시 상태를 다시 평가하면 저장된 같은 점수를 그대로 보여줍니다.

🥣 섞기 예시

토마토 소스 + 양파 + 버섯 → “토마토 소스 + 양파 + 버섯 혼합물”
난 + 그 혼합물 + 모짜렐라 → 다시 섞거나 각각 조리해서 난 피자 스타일로 완성할 수 있습니다.
